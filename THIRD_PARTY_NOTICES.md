The server-side Speech SDK authentication and SDP negotiation pattern follows the [Microsoft Azure Speech SDK Python avatar sample](https://github.com/Azure-Samples/cognitive-services-speech-sdk/tree/master/samples/python/web/avatar). Its protocol configuration and `SpeechSDKInternal-ExtraTurnStartMessage` access inform the minimal adapted signaling code. The browser token routes, unbounded sessions, and raw diagnostics of a sample are not retained.
